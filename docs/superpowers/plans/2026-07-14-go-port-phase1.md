# tncd 2.0 Phase 1 (Core Port) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Port tncd's core (AX.25 mod-8 L2 engine, KISS serial/TCP/Bluetooth transports, AGWPE frontend, INI config) to pure Go, proven by the existing pytest e2e suite running black-box against the Go binary.

**Architecture:** Single engine goroutine owns all mutable L2/bridge state (mirrors asyncio serialization — `engine.Do(fn)` ≡ `call_soon_threadsafe`, `engine.After(d, fn)` ≡ `call_later`). Exported reusable packages `ax25/`, `kiss/`, `agwpe/`; policy in `internal/`. The Python implementation stays in-tree as the behavioral reference; **when a task says "port tncd.py:N–M", open those lines and translate the logic exactly — every guard, every log-worthy state transition.**

**Tech Stack:** Go ≥ 1.25 (raised from 1.22 during Task 12: go.bug.st/serial v1.8.0 requires go 1.25.0), `go.bug.st/serial`, `github.com/godbus/dbus/v5`, `gopkg.in/ini.v1`. Tests: standard `testing` package. E2E: existing pytest suite.

## Global Constraints

- Module path is exactly `github.com/ben-kuhn/tncd/v2`.
- Pure Go only — **no cgo**. `CGO_ENABLED=0 go build ./...` must always succeed.
- Bluetooth code compiles only on Linux (`//go:build linux` + a non-Linux stub returning an error).
- Behavioral parity with tncd.py 1.3.1 is the acceptance bar; where this plan and tncd.py disagree, **tncd.py wins** — flag the discrepancy in the commit message.
- A working 1.x `tncd.ini` must load unchanged (same sections/keys, same defaults).
- Do not modify `tncd.py` or `tests/test_tncd.py` (reference implementation, frozen).
- `gofmt` and `go vet ./...` clean before every commit.
- All existing pytest unit tests (`pytest tests/test_tncd.py`) must still pass after every task (they exercise the frozen Python — this catches accidental damage to the reference).
- Python tooling runs inside the venv/nix-shell (NixOS — never bare `pip install`).

```go
package ax25

type Address struct {
	Call     string // base callsign, uppercase, no SSID suffix
	SSID     uint8  // 0-15
	CRH      bool   // C/R bit (dst/src) or H "has-been-repeated" bit (via)
}
func ParseAddress(s string) (Address, error) // "KU0HN-10", "CQ"; trailing '*' sets CRH
func (a Address) String() string             // "KU0HN-10" (SSID 0 → no suffix, no '*')

type FrameType int
const (
	UnknownType FrameType = iota
	I; RR; RNR; REJ                          // one per line in real code
	UI; SABM; SABME; UA; DM; DISC; FRMR
)
func (t FrameType) IsI() bool
func (t FrameType) IsS() bool // RR, RNR, REJ
func (t FrameType) IsU() bool
func (t FrameType) String() string // "RR", "SABM", ...

type Frame struct {
	Dst, Src Address
	Via      []Address
	Type     FrameType
	NR, NS   uint8 // mod-8; NS only for I, NR for I and S frames
	PF       bool
	Command  bool   // true = command (dst C-bit set), false = response
	PID      uint8  // I and UI frames only
	Info     []byte // I and UI frames only
}
func Parse(raw []byte) (*Frame, error)
func (f *Frame) Bytes() []byte
```

Encoding rules (must match pyham-ax25, verified by golden fixtures): each address
is 7 bytes, callsign chars shifted left 1, space-padded; SSID byte =
`crhBit<<7 | 0x60 | ssid<<1 | extBit` where extBit=1 only on the last address.
Command frame: dst CRH=1, src CRH=0 (`_cmd_frame`, tncd.py:39); response: dst
CRH=0, src CRH=1 (`_resp_frame`, tncd.py:48). Control byte mod-8: I =
`NR<<5 | PF<<4 | NS<<1`; S = `NR<<5 | PF<<4 | sBits<<2 | 0x01` (RR=0, RNR=1,
REJ=2); U (with PF bit masked out): UI=0x03, SABM=0x2F, SABME=0x6F, DISC=0x43,
DM=0x0F, UA=0x63, FRMR=0x87. PID follows control for I and UI only.

- [ ] **Step 3: Implement `address.go` and `frame.go`**

Implement per the encoding rules in the Interfaces block. Key details:
- `Parse` walks addresses 7 bytes at a time until ext bit (bit 0 of SSID byte) is set; min 14 address bytes + 1 control byte; error otherwise.
- `Command` on parse: `dst.CRH && !src.CRH` → true; `!dst.CRH && src.CRH` → false; both-equal (old v1 frames) → treat as command.

- U-frame control lookup: mask PF (`ctl &^ 0x10`) then map to type; unknown → `UnknownType` with no error (bridge logs and drops, tncd.py:1704).

package engine

type Engine struct{ /* mu, queue []func(), wake chan struct{}, quit chan struct{} */ }
func New() *Engine
func (e *Engine) Run()             // blocks; processes posted funcs in FIFO order
func (e *Engine) Stop()            // Run returns after draining current queue

type Clock interface {
	Now() time.Time

Implementation notes: unbounded FIFO (mutex + slice) with a cap-1 wake channel,
so `Do` never blocks — this is what makes calling `Do` from inside the loop safe
(that's the `call_soon` poll-deferral pattern, tncd.py:2114). `After` uses
`time.AfterFunc(d, func() { e.Do(fn) })`; `Cancel` calls `timer.Stop()` — if it
already fired, the posted fn must check its own guard (l2 stores the *Timer and
nils it, mirroring `conn.t1_handle = None`).

### Task 9: `ax25/l2` — I-frame TX path (queue, window, coalescing, ACK, Karn)

**Files:**
- Modify: `ax25/l2/l2.go`, `ax25/l2/conn.go`

- Produces: working `SendData`, `Outstanding`; internal `drainOutbound`,
  `ackFrames`, `retransmitFrom`, `updateSRTT`.

Behaviors (port exactly):
1. `SendData` fragments payload into ≤256-byte chunks, queues `(chunk, pid)`, drops when queue ≥ 512 with warning, calls `drainOutbound` (tncd.py:366–389).
2. `drainOutbound` (tncd.py:1339–1385): no-op when `remoteBusy`; while queue non-empty and `unacked < MaxWindow`: pop, **coalesce adjacent same-PID chunks up to 256 bytes**, build I-frame with current NS/NR, store raw bytes in retransmitBuf, record first-TX timestamp, NS=(NS+1)%8, unacked++. After sending any: cancel T2 (piggyback ack), start T1.
3. `ackFrames` (tncd.py:1581–1616): `newlyAcked = (nr - lastAcked) mod 8`; **reject if > MaxWindow (backwards N(R) guard)**; on progress: reset t1Polls, update SRTT from first-TX timestamps (Karn: skip retransmitted), purge retransmitBuf, lastAcked=nr, unacked -= newlyAcked (floor 0), T1 restart-or-cancel by retransmitBuf empty, then drainOutbound.
4. `updateSRTT` (tncd.py:1404–1421): first sample srtt=rtt, rttvar=rtt/2; then rttvar=0.75*rttvar+0.25*|srtt−rtt|, srtt=0.875*srtt+0.125*rtt; t1Value=clamp(srtt+4*rttvar, 3s, 60s).
5. `retransmitFrom` (tncd.py:1618–1640): walk retransmitBuf from seq; **rebuild each frame with current NR** (piggyback newer acks); drop its RTT timestamp (Karn).
6. Data-phase T1 expiry (tncd.py:1541–1579): polls++; > N2 → `Disconnected` + remove; poll #1 sends RR P=1 only; poll #2+ also `retransmitFrom(lastAcked)`; t1Value doubles (cap 60s) each expiry.
7. `Outstanding` returns `unacked + len(outQueue)` (the Y-frame fix, tncd.py:432–449).

6. `sendRRGuarded` (tncd.py:2034–2055): suppress RR F=1 when same NR sent < **3.0s** ago (uses `clock.Now()`); records time+NR on send.
7. S-frame P=1 poll response **deferred via `Defer`** so same-burst I-frames advance recvSeq first (tncd.py:2098–2116); state re-checked at fire time. **Exception: REJ P=1 responds immediately via `sendRRGuarded` (no second retransmit).**

9. `PortOffline` (tncd.py:1246–1264): cancel all timers, `Disconnected` hook for Connected/Connecting conns on that port, remove them.

```python
import os
import shutil
import sys
from pathlib import Path

def tncd_command():
    """Argv prefix for launching tncd, packet-browser style.

    Priority: $TNCD_BIN (may be multi-word, e.g. "python tncd.py"),
    then a Go binary on PATH or in the repo root, then the Python
    reference implementation.
    """
    env = os.environ.get("TNCD_BIN")
    if env:
        return env.split()
    root = Path(__file__).parent.parent
    for candidate in (shutil.which("tncd"), root / "tncd"):
        if candidate and Path(candidate).is_file():
            return [str(candidate)]
    return [sys.executable, str(root / "tncd.py")]
```
